# Support

Use this repository's issue tracker for reproducible defects in the example code,
configuration schema, dependency setup, tests, or documented output.

Use the Developer Platform repository for API documentation and tutorial issues. Route
Trader API contract or backend runtime defects to the owning `mf_openapi`/backend workflow.
Route demo account, API key, permission, and access problems to mFT or Trading Terminal
support.

Never include credentials, full account identifiers, customer endpoints, positions,
orders, raw trade responses, or recovery journals in an issue.
